xz-decompress 0.2.3, published by Tim Perry / HTTP Toolkit.

IRONCLAD modification: only the original WASM memory declaration is changed
to add a hard maximum of 64 MiB (or a lower requested page-aligned limit).
Function bodies, data sections and all other WASM sections are unchanged.
The unmodified module is retained for provenance and deterministic offline
transformation. It is hash verified and transformed before instantiation;
IRONCLAD does not instantiate the unbounded original module.

No native addon, liblzma DLL, official CPatch or xdelta3 executable is used.
