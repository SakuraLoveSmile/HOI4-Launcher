# 版本隔离 · 0.24.0

在设置页“版本隔离”中点击“添加独立版本”，输入名称，再选择包含 `hoi4.exe` 的已有游戏安装目录。创建成功后自动切换到该版本，总览顶部也可以直接切换版本。同一安装目录可以创建多个实例，分别用于不同战役或模组组合。

新实例从空播放集开始，独立保存播放集、成员启用和顺序、固定模组版本引用、DLC 选择、正常/调试模式及待应用游戏设置。游戏本地存档、继续战役信息、模组登记、游戏设置文件与缓存使用独立用户目录。界面语言、账号和启动器退出偏好属于全局设置。

原有配置会成为“默认版本”，继续使用原文档目录或安装目录 `userdir.txt` 指定的位置。新实例使用 `%APPDATA%/IRONCLAD/game-instances/<实例ID>/user-data/`。设置页显示当前安装目录和存档/配置目录。重命名不会改变目录；移除版本只移除启动器记录，保留游戏文件和整个用户目录，移除当前实例后返回默认版本。默认版本不能移除。

游戏运行或正在启动、下载/安装/验证/迁移/发布模组、本地项目处理文件、Steam 补齐请求进行期间禁止切换。暂停的 Paradox 下载保留原实例绑定；在其他实例点击继续会提示先切回原实例，不会破坏断点。原实例移除后只能取消该任务或手动恢复其配置记录，因此建议先完成或取消暂停任务再移除。

启动器不下载、复制或降级游戏。要长期保留旧版，请使用自己已准备好的独立安装目录；Steam 管理的安装和创意工坊内容仍由 Steam 统一更新，实例不会冻结共享的工坊文件。需要保留模组内容时，可使用本地二改项目的独立工作区/检查点，并在对应实例中固定项目版本。Paradox 本地安装登记和本地项目绑定用户目录；账号、订阅、联网服务及 Steam Cloud 仍属于原游戏平台的全局范围。

## 存储与失败恢复

`settings.json` schema 3 新增 `gameInstances` 和 `activeGameInstanceId`，保留顶层活动配置以兼容内部现有服务。每次保存同步活动实例的快照；切换从目标实例载入配置，全局偏好不随之回退。旧 schema 1/2 和早期未标版本配置在内存迁移，读取不改写原文件，首次保存才写 schema 3。0.23 和更早启动器不能管理此新格式，请使用 0.24 或后续版本。

实例 ID 由后端生成，目录由配置文件位置和 ID 推导，渲染器不能提交自定义用户目录。受管目录的链接/非目录项会阻止选择和启动。新建时必须存在 `hoi4.exe`，候选实例完成完整状态扫描后才原子保存；元数据损坏、路径验证或写入失败保留原活动实例及配置文件。配置损坏会保留原文件并阻止覆盖。

隔离实例的启动命令在原正常/调试参数上追加一个 `-userdir=<绝对路径>` 参数。模组扫描、设置计划、`dlc_load.json`、续存档读取与此路径一致；启动元数据已经指定 userdir 时，在写游戏文件前拒绝启动，避免路径冲突。启动事务失败只回滚当前实例已写的配置，沿用原有备份机制。游戏文件及 `userdir.txt` 不因隔离而改写。

## 验证范围

新增 Node 检查覆盖旧配置无写入迁移、同目录多实例、播放集/DLC/选项隔离、切换和重开恢复、存档和模组读取、准确启动参数、失败回滚、损坏元数据不提交、删除保留文件、运行中互斥和目录链接拒绝；主进程测试通过真实入口配合替身依赖检查原生选择、参数边界与异步互斥。断点下载测试核对错实例恢复失败不改变原始 journal，并验证切回后成功继续。

最终 Node 全套 1311/1311、相关集中组 113/113、常规界面 54 项和播放集界面 35 项通过。隐藏 Electron 常规检查通过真实 sandbox preload 和替身游戏/网络验证业务流程，无可见窗口或真实游戏进程。

版本实例另有真实 Electron 45.1.0 的隐藏专项 7/7：使用生产 preload 和隔离处理器验证四个命名 IPC，返回配置与磁盘一致，删除保留文件，默认删除拒绝；无 Node 渲染访问、网络或游戏执行。脚本 `electron scripts/test-game-instances-desktop.cjs`，证据 `test-results/game-instances-desktop.json`。退出后的一个测试临时目录清理被自动审批拒绝（仅返回 `blocked by policy`），该目录保留，不影响验证结果。

无界面 Edge 专项 21 项通过：取消选择、创建、切换、同安装多实例、重命名、失败恢复、重启、删除保留文件、运行中禁用；简中、英文及 1000px 截图已检查。应用外部请求和渲染错误均为 0。脚本为 `npm run test:instances-ui`，结果见 `test-results/game-instances/results.json`。

`-userdir` 的静态依据为本机 HOI4 1.19.4.1 程序中的 `userdir=`、`userdir.txt` 和旧式 userdir 提示字符串；隔离测试使用伪进程验证参数及文件路径，没有启动真实游戏。古早游戏版本对该参数、旧 `settings.txt` 写入格式及云存档的实际行为仍需实机确认；本轮不扩展现有仅将旧 settings.txt 作为读取回退的实现。
