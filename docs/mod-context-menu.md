# 模组右键菜单 · 0.28.0

模组管理的“已识别模组”和“当前播放集”两栏都支持右键菜单。选中一行后，也可按菜单键或 `Shift+F10` 打开；方向键、`Home`、`End` 选择操作，`Escape` 关闭并恢复焦点。菜单会保持在窗口内，点击外部、滚动列表或调整窗口大小时关闭。播放集双栏见 [播放集说明](playsets.md)，不同游戏配置的范围见 [版本隔离](game-instances.md)。

## 十项操作

| 操作           | 行为与可用条件                                                                                                       |
| -------------- | -------------------------------------------------------------------------------------------------------------------- |
| 修改显示名称   | 输入 1–128 字符并保存为当前版本的别名。                                                                              |
| 汉化名称并记住 | 尝试读取已有中文名称，打开可编辑对话框，确认保存后记住；没有中文标题时手动填写。                                     |
| 恢复原名称     | 清除当前版本保存的别名，重新显示描述文件中的名称；没有别名时禁用。                                                   |
| 复制模组 ID    | 远端模组复制 Steam／Paradox ID，本地模组复制其登记 ID。                                                              |
| 打开模组目录   | 打开当前扫描确认的内容目录；目录缺失时禁用。                                                                         |
| 打开工坊页面   | Steam 打开工坊详情；Paradox 显示“打开模组来源页”；没有远端来源时禁用。                                               |
| 更新模组       | Steam 请求普通优先级下载；Paradox 使用原下载流程并保留当前播放集的固定版本；本地模组和二改项目禁用。                 |
| 创建二改项目   | 跳转“本地项目”并打开创建对话框，预选右键模组及项目名；确认后创建独立工作区。来源缺失、已有二改项目或游戏运行时禁用。 |
| 移出当前播放集 | 只移除当前播放集的成员和引用，不卸载内容；非成员时禁用。                                                             |
| 删除模组       | 确认后按来源取消订阅、卸载或移入回收目录，并清除当前版本所有播放集中的引用；详见下方。                               |

“创建二改项目”复用“本地项目”的原有创建流程，可编辑项目名，默认不勾选原版基线确认。只有确认来源未经个人修改时才勾选；取消不创建项目，创建成功后直接显示新项目。副本不会继承作者的发布身份；原版和当前播放集的启用状态不因创建而改变，后续可在项目中主动选择使用工作区。完整流程见 [本地二改项目](roadmap-2.md)。

## 显示名称和汉化

显示名称保存在 `settings.json` 的 `modDisplayNames` 中，按模组 ID 记录 `{name, kind}`；`kind` 为 `custom` 或 `translated`。每个版本实例分别保存，切换和重开后保留。删除模组后别名仍保留，重新安装同一 ID 可继续使用；“恢复原名称”才清除该记录。旧配置自动获得空映射，每个实例最多 10,000 条。

别名用于启动器展示与搜索，搜索同时保留原名、远端 ID 和标签。原描述文件名称、依赖识别和启动引用保持原始身份，播放集交换也使用原始来源元数据。

“汉化名称并记住”优先采用原名称中已有的中文；Steam 模组可通过已连接的 Steam 客户端读取 `schinese` 标题，必要时先连接 Steam。没有已有中文标题、来源不支持或查询失败时，可以手动输入。所有结果都先供用户编辑确认；没有调用外部翻译或机器翻译服务。

## 更新与删除的影响

Steam 更新表示 Steam 接受下载请求，不能据此认定文件已经安装完成；下载和带宽仍由 Steam 管理。Steam 删除实际执行取消订阅，工坊物理文件由 Steam 管理和移除。该订阅及内容在版本实例之间共享，因此其他版本也会受影响；启动器只清除当前版本所有播放集中的成员、加载顺序和远端引用，其他版本的记录可能因此变成缺失项。

Paradox 更新复用现有下载、授权、验签和安装事务；当前播放集固定了版本时仍请求该版本。删除只接受当前游戏用户目录下可验证的 IRONCLAD 受管安装，使用原卸载流程并保留恢复备份，不取消 Paradox 账号订阅。没有成功移除受管安装时不会清除播放集引用。

本地删除只适用于当前游戏用户目录 `mod/` 内、由该目录下普通 `.mod` 文件直接登记的独立内容目录或 ZIP。二改项目、外部目录、无可信内容位置、共享内容、链接或目录联接，以及非受管 Paradox 安装不能从这里删除。实际删除前会重新扫描磁盘登记并核对描述文件与内容身份；按钮可用也可能因文件随后变化而拒绝操作。

## 本地回收与手工恢复

本地删除将内容和登记文件移动到当前游戏用户目录：

```text
<userData>/ironclad-mod-trash/<UUID>/
  content/ 或 archive.zip
  registration.mod
  manifest.json
```

这里的 `<userData>` 是设置页显示的游戏用户目录；隔离实例通常位于 `%APPDATA%/IRONCLAD/game-instances/<实例ID>/user-data/`。`manifest.json` 保存删除时间、模组 ID、原用户目录，以及每项原路径与回收名称。

内容移动成功后才提交当前版本全部播放集的引用清理。设置保存失败会尝试移回原位；若原位置出现新文件，不覆盖它，保留回收内容并报告路径。回收目录不会自动清空，也没有自动恢复按钮或启动时自动恢复流程。

需要恢复时，先关闭游戏和启动器，按清单将内容及 `registration.mod` 移回各自原路径；原位置已有内容时先核对，避免覆盖。刷新后重新加入所需播放集，删除前的成员关系和顺序不会自动恢复。别名记录仍可沿用。

## 互斥和验证范围

界面忙碌时禁用菜单操作；游戏运行时禁用更新和删除，显示名称仍可修改。主进程对内容操作继续执行启动中、目录切换、缓存维护、下载／安装、发布、二改项目、迁移恢复和缺失模组补齐等互斥检查。IPC 只接收模组 ID，路径来自当前实例的可信扫描；异步操作核对实例与用户目录变化。

0.25.0 最终全量 Node **1347/1347**、菜单界面 **41** 项、常规界面 **54** 项、播放集界面 **35** 项、隐藏 Electron、构建与语言检查通过。菜单专项覆盖两栏、九项操作、别名重开和实例隔离、中文名称手工回退、来源删除、运行中保护、键盘、窗口边缘、英文与 1000px 布局。首次并行验证中的一个诊断写入等待超时已保留原记录，诊断专项 **39/39** 及单独全量复跑通过，未为此修改代码。
