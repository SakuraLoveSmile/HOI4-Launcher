# 播放集双栏管理 · 0.22.0

模组管理页同时显示左侧「已识别模组」与右侧「当前播放集模组」。播放集就是旧版的预设，直接沿用现有配置，不重命名用户保存的内容，也不需要重新导入。

## 使用

- 顶部下拉框切换播放集；新建默认是空集，可勾选复制现有成员。复制按钮预选复制成员，并保留停用项、顺序、版本引用和 DLC 选择。支持重命名及确认删除，始终保留至少一个播放集。
- 左侧加号将模组加入当前播放集并启用。已加入的成员显示勾号，即使已停用也不会重复加入。来源、状态、名称排序与搜索只影响左侧展示；「加入筛选结果」仅添加当前可见且可用的新成员。
- 右侧开关只改变启用状态，叉号只移除播放集成员，保留磁盘上的模组。拖拽或上下箭头调整加载顺序；搜索时仍按完整成员列表的位置移动，不删除隐藏成员。
- 两侧搜索互不影响。右侧「启用筛选结果」仅启用当前可见且可用的成员；「全部停用」作用于整个当前播放集。简化显示缩短行高，不修改播放集数据。
- 官方播放集导入、JSON 导入/导出、本地模组创建与详情入口保留。JSON 仍遵循官方格式，省略本地模组和 DLC，界面有提示。

所有修改自动保存，失败显示错误且不假装添加成功。播放集切换后重新扫描完整状态，及时更新固定 Paradox 版本、缺失项和加载顺序参考。0.25.2 起不再从描述文件名称列表推断必需依赖，详见 [误报修复](mod-load-order.md)。编辑播放集只写启动器配置，点击启动时才按原有备份与启动流程应用游戏加载配置。
