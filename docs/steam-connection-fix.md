# Steam 连接修复 · 0.20.1

2026-10-29。用户当前 0.20.0 窗口曾显示“无法连接 Steam”，本次手动重试恢复连接并显示订阅列表。旧日志只记录 IPC 返回成功，没有保留失败阶段，因此不能确定最初失败发生在 SDK 初始化还是首次订阅读取。

本次修复两个已用隔离测试复现的问题：

- SDK、游戏和账户验证成功后，首次订阅列表或详情读取失败不再撤销连接。显示原有刷新警告，后续刷新成功后清除警告，不重复初始化 SDK。
- 首次连接中的原生读取一直不返回时，RPC 超时会清理该只读后台进程。下次点击连接创建新进程，不再排入永久阻塞的旧队列。已有成功连接或发送过订阅、取消订阅、下载、补齐、发布请求的进程不会被这一恢复逻辑自动终止，写操作不会自动重放。

此外，`steam:connect` 返回 `connected:false` 会正确记录为失败，日志只记录固定提示，不记录原生自由文本或账号资料。

## 验证

- Steam 服务、worker、补齐和主进程 IPC 定向测试 120/120 通过，包括初次读取失败后恢复、连接超时后重新建进程，以及已连接/有未确认写请求时不终止进程。
- 完整后端 1,189/1,189、常规无界面 UI 54 项及隐藏 Electron 桌面集成通过；构建和修改文件格式检查通过。
- 无界面 Steam 补齐流程通过：43 项计划、分页、停用状态与顺序、取消、换号、未知回执和重开不重放；使用模拟 Steam，应用外部请求为 0。
- 本机 Electron 45.1.0 utility process 加载新 0.20.1 包中的生产 worker 和真实 Steam SDK，只读连接 HOI4 并返回 358 个有效项目；旧版便携程序窗口也恢复已连接。部分订阅项目不可用时保留列表不完整提示。这些结果不代表订阅变更、下载或发布验收通过；新便携 EXE 的自解压启动流程本轮未运行。
