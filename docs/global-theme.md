# 全局配色修正 · 0.21.1

0.21.0 将炭灰、暖白、柔和金色限制在 `.workshop-shell` 内，离开 Steam 工坊后，设置等页面仍恢复原来的橄榄绿主题。0.21.1 把主题定义移至全局 `:root`，将页面、侧栏、标题栏、正文、表单、按钮、提示和弹窗中的旧颜色替换为共享变量。工坊作用域仅保留页面布局规则，其他页面的标题与间距保留。

背景为 `#111419`，面板为 `#191d24`，正文为 `#e9ebef`，强调色为 `#dfc38c`；成功和连接状态使用绿色，错误提示使用红色。首页 SVG 引用相同变量，Electron 原生窗口底色同步为 `#111419`。此版本仅调整主题及版本号，不修改 Steam 连接、订阅、游戏配置或下载行为。
