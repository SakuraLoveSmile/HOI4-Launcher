# IRONCLAD · 钢铁雄心 IV 第三方启动器

Windows x64 / Steam HOI4。技术栈：Electron 45、React 19、JavaScript、Vite 6、Node.js 内置 SQLite；Steam 使用独立后台进程中的 steamworks.js。

**0.28.0 加入右键创建二改与启动器更新。** 模组管理两栏可右键“创建二改项目”，自动选中来源并沿用独立副本流程。设置页可检查 GitHub 正式版、下载校验、取消和安装重启；便携版替换保留旧程序备份，安装前阻止游戏及文件任务冲突。发布工作流生成更新清单，首次启用需在仓库创建正式 Release。详见 [启动器更新](docs/launcher-updates.md) 与 [模组右键菜单](docs/mod-context-menu.md)。

**0.27.0 加入战役与组合工作流。** 战役档案记住存档配置、备份和备注，继续前检查变化；组合快照保存实际启用 Mod 文件并恢复为独立播放集；覆盖检查提供同路径、`replace_path`、重复事件／国策 ID 的来源证据。游戏统计支持两次游玩曲线、摘要、配置差异与备注；总览可切换并记住紧凑首页。使用与数据边界见 [五项改进](docs/five-improvements.md)。

**0.26.0 加入游戏统计。** 每次启动到退出保存一条性能记录，展示运行时长、CPU 和内存的平均／峰值、可查看采样点的趋势与历史。独立后台采集器每五秒采样，关闭启动器后继续记录；当前不采集 FPS 或游戏日期推进速度。详见 [游戏统计](docs/game-performance.md)。

**0.25.2 修复模组依赖误报。** 描述文件中的 `dependencies` 也可用于加载顺序或兼容声明，不能直接视为必须启用的前置。总览、双栏和详情取消这种推断警告，原始声明作为“加载顺序参考”保留；必需前置请核对作者说明。详见 [依赖误报修复](docs/mod-load-order.md)。

**0.25.1 修复部分 Mod 封面不显示。** 兼容图片真实格式与文件名后缀不一致、缺少 `picture` 字段或后缀、编辑器附加尾部及静态 WebP 来源元数据；工坊失败封面可手动刷新重试。本机只读复查新增恢复 188 张封面，369 张全部通过浏览器解码。详见 [封面修复](docs/mod-thumbnails.md)。

**0.25.0 加入模组右键菜单。** 模组库和当前播放集都可右键改名、汉化并记住、恢复原名、复制 ID、打开目录或来源页、更新、移出播放集和删除。显示名称按版本实例保存，保留原始描述文件名称；汉化使用已有 Steam 中文标题或手动输入。删除按来源处理，并明确提示共享 Steam 订阅的影响；本地内容移入带清单的可恢复目录。详见 [模组右键菜单](docs/mod-context-menu.md)。

**0.24.0 加入版本隔离。** 在设置页“版本隔离”中添加本机旧版或独立安装，也可为同一游戏目录建立多个实例。每个实例独立保存播放集、DLC 选择、游戏设置和本地存档/模组登记/缓存；总览可直接切换。原配置沿用为默认版本，移除版本保留游戏文件与存档。Steam 工坊内容仍共享，启动器不下载或复制游戏。详见 [版本隔离](docs/game-instances.md)。

## 使用

工坊筛选增强版：[IRONCLAD-0.26.0-workshop-filters-portable.exe](release/workshop-filters/IRONCLAD-0.26.0-workshop-filters-portable.exe)。在创意工坊点击“更多筛选”可组合包含和排除标签，顶部提供新增排序与热门时间范围；使用原有配置。详见 [筛选说明与验证](docs/workshop-redesign.md)。

打开便携版 [IRONCLAD-0.27.0-portable.exe](release/IRONCLAD-0.27.0-portable.exe)。旧版产物保留。便携版需要短暂解压；配置保存在 Windows 用户目录。新功能见 [五项改进](docs/five-improvements.md) 与 [游戏统计](docs/game-performance.md)，依赖修复见 [依赖误报](docs/mod-load-order.md)，封面见 [模组缩略图](docs/mod-thumbnails.md)，菜单功能见 [模组右键菜单](docs/mod-context-menu.md)，旧版与独立安装见 [版本隔离](docs/game-instances.md)，本地二改见 [本地二改与上游更新](docs/roadmap-2.md)，播放集见 [播放集说明](docs/playsets.md)，早期路线图状态见 [ROADMAP.md](ROADMAP.md)。

1. 自动检测 Steam 安装；必要时选择包含 `hoi4.exe` 的目录。
   要玩旧版或独立安装，在设置页“版本隔离”点击“添加独立版本”，命名并选择已有安装目录；之后可从总览切换。
2. 在模组管理中选择或创建播放集，点击左侧加号添加模组，在右侧设置开关和顺序；两栏均可右键管理名称、更新或删除，也可导入官方播放集/JSON。
3. 为当前预设选择 DLC，在设置页修改游戏显示与语言偏好。
4. 保持 Steam 运行，返回总览选择正常/调试启动，或继续上次存档。

初始预设为空，表示原版战役。打开启动器不启动游戏，扫描不修改游戏和工坊文件。本地启动无需 Paradox 账户。游戏设置只在点击启动时应用，原文件自动备份。

## 当前能力

- 战役档案绑定本地存档，保存配置、备注和备份；继续前核对版本、Mod 顺序与内容、DLC 和设置。恢复配置新建播放集，恢复存档前保留当前字节。
- 当前启用组合的实际 Mod 内容快照，核验后恢复为独立本地项目和播放集；扫描同路径文件、`replace_path` 和重复事件／国策 ID，提供来源文件／行号与有界证据预览。覆盖提示不能证明必然不兼容。
- 可持久化紧凑首页，集中继续战役、当前组合、配置摘要和最近游玩，可切回完整首页。
- 游戏每次启动到退出的本地性能记录；CPU／内存均值和峰值、趋势、采样点查看与历史，独立后台采集器在启动器关闭后继续工作。统计开关只影响以后启动的游戏，采集失败不阻断游戏。详见 [指标与验证边界](docs/game-performance.md)。
- Steam 多游戏库、文档目录重定向和游戏 `userdir.txt` 检测。
- 本地、Steam 和已注册 Paradox 模组扫描；搜索、来源/状态筛选、排序、版本兼容提示、加载顺序参考、详情与目录入口。模组库、总览成员和详情按需显示本地目录或 ZIP 内的封面，缺图或解码失败时回退图标；不联网取图。格式与安全边界见 [模组缩略图](docs/mod-thumbnails.md)。
- 预设增删/复制/重命名、成员停用/移除、拖动与箭头排序；独立 DLC 选择。已启用的缺失内容和无法核实的固定版本阻止启动。
- 两栏模组右键菜单与键盘入口；按版本保存显示别名和中文名称，按来源更新、取消订阅或受管卸载。本地删除保留回收内容及恢复清单，清除当前版本所有播放集引用并保留别名。
- 从只读 SQLite 快照导入官方预设；官方 JSON 文件/剪贴板交换保留顺序、关闭成员和版本引用。
- 官方正常/调试/继续游戏参数、重复启动保护、进程状态。
- 八项官方游戏设置，保留未知字段；写入或进程创建失败回滚。
- 创建/编辑本地模组；保留发布标识和未知字段，原描述文件备份。
- Steam 创意工坊创建/更新发布：准备独立内容快照，审阅文件/大小/可见性后确认上传；所有权检查、实时进度、协议处理和已创建项目 ID 持久化。
- Paradox Mods 创建/更新发布：账号与目标所有权检查、独立快照及 ZIP、流式上传、服务端最终状态核对。提交前保存发布标识，未知结果可只读查询恢复，避免重复创建；仅在快照中调整推荐游戏版本。V1 接口采用服务端默认可见性，发布后显示实际返回值，请在来源页核对。
- 官方新闻、社区/支持/DLC 商店入口；匿名 Paradox Mods 搜索、翻页与缓存。
- Paradox 主动登录、退出、刷新、取消和系统加密会话保存，密码不落盘。
- Steam 主动连接、浏览、订阅/取消订阅、下载和更新状态；14 类标签支持多选交集/并集和排除，提供 6 种排序及热门趋势时间范围，搜索与翻页保留条件。普通下载优先级，不暂停其他 Steam 下载。详见 [创意工坊筛选](docs/workshop-redesign.md)。
- Steam 当前预设缺失项补齐：先连接并审阅账号、名单和启用状态，确认后逐项订阅并请求普通优先级下载，包含关闭成员且保留原顺序与开关。结果持久保存，重开不自动重放；结果未知时停止后续项。“停止后续请求”不会撤回当前请求或 Steam 已接受的下载。仅磁盘刷新确认文件到位后解除缺失，详见 [Steam 缺失模组补齐](docs/steam-missing-mods.md)。
- Paradox 公开完整包下载、SHA-256 校验、安全 ZIP 解压、安装/更新/卸载、取消和限速；更新失败保留旧版，异常退出后恢复安装事务。预设缺失的 Paradox 内容可直接发起下载，受限历史版本不会绕过授权。
- Paradox 完整包签名信任链：固定官方生产根，验证仓库公钥认证、原始 `repository.json` 和 `manifest` 的 OpenPGP 分离签名，再按可信清单核对 ZIP 的 SHA-256。每次解析重新检查根和仓库钥撤销状态；仅兼容已核实官方旧密钥的过期与认证摘要，不放宽内容签名要求。范围见 [签名验证](docs/pdx-signatures.md)，第三方库材料及替换方式见 [OpenPGP.js](docs/third-party-openpgp.md)。
- Paradox 下载身份选择：默认匿名，也可显式使用当前账号下载获准访问的固定历史版本及私有完整包。公钥、元数据、分离签名、清单与 ZIP 各自取得资源授权，授权地址只保留在内存中。任务绑定一次登录会话，退出、换号、重新登录或登录过期会中断；继续下载重新授权并验签。账号凭据不发往内容 CDN。范围见 [受保护仓库](docs/pdx-protected-repository.md)。
- Paradox 完整包和已选补丁下载暂停、保存断点和重启后手动续传；目标完整包、实际传输包与旧源计划分别绑定。继续时重新验签、授权和核对片段；已选补丁或旧源改变会停止并保留片段，不换成其他下载。服务器不接受 Range 而返回 200 时，从头下载同一传输包。补丁应用及安装阶段不可暂停；重开启动器不会自动恢复联网。
- 保存实际收到或重建并核验的原始 ZIP，核对源、暂存及最终文件的大小和 SHA-256；默认最多 10 GiB、32 项，暂不自动清理。普通更新只在补丁比目标 complete 更小、旧版重新验签并与受管安装摘要一致、对应原始 ZIP 缓存可用时选择差分；初选前缓存或旧源优化不可用则下载目标 complete。不会重新压缩已安装目录，也不接管官方内部缓存。选定补丁后的授权、签名、传输、容器、旧源或目标校验错误均停止。边界见 [增量下载与原始归档缓存](docs/pdx-delta-core.md)。
- 受管 Paradox 模组“验证并修复”：检查可信摘要对应的缺失、改动、多余或不安全文件及注册状态。需要可信 ZIP 时先请求官方 `files/<Size>_<带填充Base64URL的SHA-256>`；仅实际内容 404 且可信仓库声明 `-1` 安装补丁时，独立验签并应用该补丁。未声明 `-1` 的仓库保留 404 后取同版 complete 的兼容行为；其他错误不触发回退，已选补丁失败也不静默改取 complete。账号模式各资源独立授权，重建 ZIP 必须匹配目标 complete 的字节数和 SHA-256，再交给原事务修复，保留旧内容、注册备份与预设。旧安装无基准且健康时只补建基准。公开身份的健康验证不联网；账号身份先核对登录会话，健康时不请求内容资源或 ZIP。此范围仍以完整模组 ZIP 为安装单位，不提供单个解压文件的网络修复。详见 [模组验证与修复](docs/pdx-repair.md) 与 [内容地址及补丁路径](docs/cpatch-download-paths.md)。
- Paradox 账号订阅列表、订阅/取消订阅；请求绑定当前账号，区分写入成功但列表刷新失败与结果未知，避免重复提交。账号订阅与本地安装分别管理。
- Paradox 模组自定义位置：设置页预览现有受管版本、文件和大小，确认后迁移到选定目录，支持恢复默认位置、复制阶段取消、失败回滚和重启恢复；预设及固定版本保留。
- 缓存备份/清理/恢复和脱敏诊断；含用户内容的清理项默认不选。诊断默认保存 ZIP，包含报告、最近 200 条内存事件和跨重启日志；以 `.json` 结尾的文件名保留 JSON 格式。受管日志最多 3×2 MiB，磁盘故障或超时不阻塞普通操作，导出附带持久化状态。账户事件不记录自由文本错误，也不收集报告路径中的文件或官方日志，详见 [诊断导出](docs/diagnostics.md)。
- 设置页可切换官方十二种界面语言，重开后保留；旧版配置默认简体中文。新增西班牙语、日语、韩语、波兰语、葡萄牙语、俄语、土耳其语；各词典覆盖当前界面键。切换界面语言保留游戏语言、模组/预设名称、路径、远端描述和新闻原文；模组显示别名由右键菜单独立管理。文件选择框、关闭确认的应用文案同步切换，系统按钮遵循 Windows 语言。覆盖范围和回退规则见 [界面语言](docs/launcher-i18n.md)。

账号和 Steam 功能经过隔离测试；2026-10-29 的连接修复另完成本机 Steam 只读连接与订阅列表验证。真实订阅变更、下载、发布及 Paradox 账户仍待联调。自动化回归使用模拟 Steam，不登录账户或启动游戏。

## 数据与恢复

- 设置：`%APPDATA%/IRONCLAD/settings.json`。兼容旧 MVP 配置；损坏配置保留并阻止覆盖。
- 版本实例：同一设置文件的 schema 3 保存各实例配置；旧配置只读迁移，首次保存写入新格式。新增实例的本地存档、设置和模组登记位于 `%APPDATA%/IRONCLAD/game-instances/<实例ID>/user-data/`，默认实例继续使用原文档目录或 `userdir.txt`。移除记录不删除目录；新格式需使用 0.24.0 或后续启动器。
- 模组显示名称：各实例的 `modDisplayNames` 保存自定义／中文别名，删除模组仍保留；“恢复原名称”清除别名。原描述文件和依赖名称不改写。
- 本地模组回收：当前游戏用户目录 `ironclad-mod-trash/<UUID>/` 保存内容、登记文件及 `manifest.json`。关闭游戏和启动器后可按清单手工移回，随后重新加入播放集；没有自动恢复按钮，不自动清理。详见 [删除与恢复](docs/mod-context-menu.md#本地回收与手工恢复)。
- 自有诊断日志：同目录 `logs/`，每次运行创建独立会话；最近 3 个受管文件按容量轮换。正常退出最多等待 2 秒写入，强制终止时最后排队或未完成记录可能丢失。
- 自有加密会话：同目录 `account.session`，只保存系统加密的刷新令牌。退出账户删除，不读取官方账号存储。
- Steam 发布记录：同目录 `publishing/history.json`；新建工坊 ID 与本地描述文件绑定。失败后先核对保存的目标 ID，再选择更新，避免误建重复项目；不会重写本地模组 ID 或破坏预设引用。
- Steam 补齐记录：同目录 `steam-missing/missing-mods.json`，v2 采用首行快照和逐行意图/结果，终结时原子合并为单个快照，避免每个条目重写完整任务；兼容读取 v1。重开只恢复记录，不启动 SDK 或重放订阅/下载；遗留进行中项目标为结果未知，未提交项保持未提交。先连接 Steam、刷新核对，再重新审阅仍缺失的内容。
- Paradox 发布记录：同目录 `publishing-pdx/history.json`；与 Steam 编号独立保存。结果待确认时使用“检查发布状态”，不要另建重复项目。发布压缩包必须小于 5 GiB，源文件采用本应用的 200 GiB 上限；新建项目需模组内 PNG/JPEG 预览图，最大 1,000,000 字节。
- Paradox 安装：同目录 `pdx/installations/`，在游戏用户目录登记 `pdx_<id>_<revision>.mod`。卸载注销描述文件，旧内容保留为恢复备份。下载记录在 `pdx/downloads/downloads.json`，0.7.0 升级为 v2；继续管理断点请使用 0.7.0 或后续版本。暂停或中断后可点击“继续下载”，也可取消后另开任务。无法确认归属、被改动或含未知尾部的临时包保留并显示路径；旧 v1 无校验记录的片段不会用于续传。详见 [下载暂停与恢复](docs/pdx-resume.md)。
- 原始归档缓存：同目录 `pdx/archives/<SHA-256>.zip`。保存实际收到或重建且完整核验的 ZIP，不保存账号或授权 URL；未知片段保留并计入预算，遗留锁不会自动删除。差分旧源每次重新验签并核对整个缓存，缓存不替代在线权限/签名核对或安装验证。
- 自定义内容目录为 `<所选目录>/hoi4/ironclad`，数据库与恢复日志保持在原应用数据目录；位置按游戏用户目录保存。迁移只处理本应用有记录的当前及保留版本，官方安装和 v1 未索引的旧内容原地保留。新安装记录采用 v2，需使用 0.5.0 或后续版本管理。恢复未完成时阻止启动，可在设置页重试；细节见 [迁移与恢复](docs/pdx-relocation-plan.md)。
- 游戏用户目录：通常是 Windows 文档下 `Paradox Interactive/Hearts of Iron IV`，以设置页为准。
- 游戏配置：`dlc_load.json` 和 LFV0 的 `pdx_settings.txt`。原文件旁的 `.ironclad-backup-*` 为修改前备份。
- 手工恢复游戏设置/描述文件：先关闭游戏和启动器，将选定备份复制回原文件名。后续游戏崩溃不自动回滚已成功启动的配置。
- 缓存备份：`ironclad-cache-backups/`，从设置页恢复；如原位置有新内容，会为其另建备份。历史备份不自动删除。
- 未注册工坊项只在启动时生成带管理标记的 `mod/ironclad_ugc_*.mod`，不覆盖用户描述文件。
