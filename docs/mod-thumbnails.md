# 模组缩略图

已实现模组库、总览成员和详情封面，读取本地、Steam、已注册 Paradox 模组描述文件中的 `picture`。支持普通内容目录及 ZIP 归档中的相对路径；不联网，不修改描述文件、预设或模组内容。

0.25.1 修正部分已安装 Mod 有封面却只显示图标的问题。图片类型改由经过校验的实际内容确定，允许文件名为 `.png` 而内容实际为 JPEG、WebP 或 GIF；返回的 data URL 使用实际 MIME。`picture` 缺失或目标不存在时，只尝试内容根目录的 `thumbnail.png/jpg/jpeg/gif/webp/bmp`；无扩展名的合法相对路径先尝试原文件，再尝试同目录的这六种后缀。显式路径优先，ZIP 采用相同规则，不依赖条目排列顺序。越界或不支持的显式路径仍回退图标，不搜索任意图片或其他模组。

状态中的 `picture` 可补为本次扫描解析出的相对封面候选，供界面按需读取；描述文件和导出元数据保持原样。ZIP 的真实图片仍在读取时确定，候选存在不代表图片一定可解码。

渲染器只提交已扫描的模组 ID，不能指定文件路径。主服务扫描后登记图片源快照，单图读取不重新扫描整库。后台状态扫描发现源未变时复用登记记录，避免慢图片读取被定时扫描反复作废；路径、内容或身份变化则需刷新后重新登记。

列表仅在图片接近可视区域时读取，预取边距为 160 像素；列表与详情共享同一次扫描中的模组读取结果。后台及前端各限制最多两张并行处理。前端先调用浏览器解码，再绘制到最长边不超过 512 像素的 canvas 显示副本，不放大小图片；GIF也显示静态封面，不持续播放动画。打开空预设的总览不批量读取整个库的封面。缺图、不支持、文件变动、接口错误或浏览器无法解码时显示原有图标；详情不留空封面区域。刷新换用新扫描结果，过期组件或旧模组对象的异步结果不覆盖当前封面。

## 文件与格式边界

- 单图最多 8 MiB、单边 8192 像素、总像素 16 Mi；实际图片签名、结构和返回 MIME 须相符，文件名后缀不作为实际格式的证明。
- 支持 PNG、JPEG、GIF、静态 WebP、未压缩 BMP。APNG、动画 WebP、压缩 BMP、SVG/HTML 等使用图标回退。JPEG/WebP 的后端检查为结构及尺寸检查，最终由浏览器解码；不能把结构通过当作完整像素解码通过。
- 封面专用 `validatedCoverRaster` 解析 PNG 的 IEND 或 JPEG 的真实 EOI，在主体通过校验后丢弃编辑器附加的尾部数据；不改原文件，不把尾部数据交给渲染器。JPEG 段内嵌入的 EOI 不会误截断图片。其他调用方的 `validatedRaster` 仍拒绝附加尾部。静态 WebP 兼容有界的 C2PA 来源元数据，不解释其载荷。
- GIF最多256帧、累计解码像素不超过16 Mi；每帧LZW指令预算为 `max(4096, 帧宽 × 帧高 × 2 + 2)`，包括不产生像素的clear指令。重置只使旧字典不可达，不重复清空4096项；过多clear或超预算输入直接回退，避免小尺寸图片消耗无界解析工作。
- 路径必须在模组内容内。绝对路径、越界、ADS、Windows 特殊别名、硬链接、符号链接和目录联接等不提供图片；打开前后核对文件与祖先目录身份、体积和修改时间。
- ZIP 按条目惰性读取，不解压落盘；拒绝重复名称、链接、加密、异常长度和 CRC 不符。最多 100000 条目、20 GiB 归档、64 MiB 读取预算，图片仍受 8 MiB 限制；超限只回退图标。

## 验证

0.25.1 对本机 391 个 Mod 做只读复查：修复前 181 张封面可读，修复后 369 张可读且全部通过无界面 Edge 的实际解码与 512 像素显示副本生成，新增恢复 188 张，没有原正常封面退化。剩余 22 项缺少可用的已声明／常规缩略图或模组内容，不从任意图片猜测封面。扫描前后启动器配置字节不变，无外部网络请求。证据见 `test-results/0.25.1/local-cover-audit.json`。

新增回归覆盖实际格式与后缀不一致、缺失字段、无后缀路径、目录与 ZIP 的候选优先级、PNG/JPEG 尾部裁剪、EXIF 内嵌 EOI、静态 WebP C2PA 及源文件不变，最终全量 1356/1356 通过。封面界面专项验证六张有效封面，包含无 `picture` 的根目录缩略图和 PNG 文件名的 JPEG；将两者加入当前播放集后，两栏封面一致，刷新后仍显示并共用读取。工坊界面 41 项通过，包括同 URL 加载失败后点击“刷新本地模组”恢复。普通状态轮询不会反复重试失败的 CDN 图片。汇总与便携包校验见 `test-results/0.25.1/verification-summary.json`。

`tests/mod-thumbnails.test.cjs` 使用真实微型 PNG/JPEG/GIF/WebP/BMP、临时目录与 ZIP，覆盖路径、身份、结构、大小、并发、句柄关闭和读取中刷新。`tests/main-migration.test.cjs` 读取真实 main 源码并注入全部副作用，检查命名 IPC 的来源窗口边界及只读行为。

`scripts/test-mod-thumbnails-ui.mjs` 使用真实后台服务和独立无界面 Edge，验证四种模组来源、解码回退、详情共享、512 像素显示副本、刷新后封面变化及预设不变；网络路由阻止非本机请求，产品未发起外部图片请求。环境中杀毒软件注入的脚本请求单独计数并阻止，不归入应用请求。

封面复查不执行真实游戏或 Steam SDK；Electron 运行时检查另见版本验证汇总。
