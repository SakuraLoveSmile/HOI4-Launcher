# Steam 创意工坊界面与筛选

## 当前筛选

浏览区的分类扩展为 14 种：架空历史、玩法、画面、翻译、平衡、事件、修复、历史、地图、军事、国策、音效、科技、实用工具。顶部分类菜单可快速选择单个标签；“更多筛选”可以选择多个包含标签、匹配全部或任一标签，以及排除标签。同一个标签不能同时包含和排除。选择后点击“应用筛选”一次提交，取消或收起不会应用草稿。

排序包含本周热门、最新发布、最近更新、最多订阅、最高好评、常用前置、热门合集成员，并保留热门作品、热门趋势和赞数最多。本周热门固定使用 Steam 最近 7 天趋势；最高好评使用 Steam 综合评分而非简单赞数；常用前置按被其他非合集项目引用的次数排序，热门合集成员按被合集收录次数排序。后两项查询的对象仍是模组。热门趋势另可选择最近 7、30、90、365 天。热门作品在填写搜索词时沿用 Steam 的文本相关性排序。

语言菜单提供全部语言、仅中文内容和非中文内容。Steam 的返回语言参数只选择标题/简介的本地化版本，公开语言标签也没有覆盖中文模组，因此根据作者的标题、简介和语言标签识别中文，并在界面说明可能遗漏。日文假名、韩文会阻止纯汉字启发式判定，明确中文标签及“中文/汉化”等标记优先。此识别不验证模组内全部本地化文件；非中文包含未识别为中文的模组。

语言筛选保留 Steam 全局排序，连续读取原始分页，每次最多扫描 4 个原始页、收集 50 个匹配项，15 秒后不再开始下一页。游标可以从原始页的中途继续，避免丢失后半页匹配项；没有匹配但仍有后续内容时允许继续下一页。界面显示“本页匹配项”，不把未过滤的总数或已扫描数当作全工坊语言结果总数。搜索、分类、排除和排序改变后回到第一页。

Steamworks.js 0.4.0 只接受排序枚举 0–19。新增 Windows x64 查询适配器通过 Koffi 3.3.6 调用同一 Steam DLL 的原生 20/21 枚举，复用已连接会话。它只在隔离 Steam worker 内加载和轮询（单页最多 6 秒），同步读取自身回执以避免 SDK 回调泵消费它，所有路径释放查询句柄。普通排序继续走原 SDK；未连接时不加载原生模块。

已应用标签显示为可移除的小按钮；“清空筛选”重置标签、匹配方式、排序、语言和趋势范围，并返回第一页，保留搜索关键词。“我的订阅”对已读取的订阅列表应用相同的标签和语言规则，提供最近更新和最多订阅两种本地排序；右侧订阅栏继续独立提供搜索和安装、更新、下载状态筛选。

前后端共用 `src/workshop-filters.json`，便携包白名单包含该文件。新增文案覆盖全部十二种界面语言。分类筛选依据作者的 Steam 标签，语言使用上述文本识别；未加入没有数据依据的兼容版本或大小筛选。

本次界面自动验证 87 项通过，涵盖新增排序、语言连续分页/返回/结束、与分类和搜索组合、订阅本地筛选、清空，以及中英文 1440×900、1000×740 布局。真实只读查询验证原生 20/21 排序和适配前后的原 SDK 调用成功；未变更真实 Steam 订阅。完整报告见 `test-results/workshop-sorting/verification-summary.json`。

## 0.21.0 界面改版记录

根据用户提供的第三方启动器截图重新设计：主区域采用大封面网格，上方提供搜索、分类、排序和分页；右侧常驻订阅列表，支持名称或 Workshop ID 搜索及安装、更新、下载状态筛选。封面和标题可打开详情，订阅、下载、检查更新和取消订阅继续使用原服务，退订保留确认与预设引用提示。

工坊页面的外壳、边栏、控件和对话框统一为炭灰背景、暖白正文、柔和金色强调；下载活动与连接状态单独标色。宽窗口为四列卡片，较窄窗口自动减列、搜索控件换行，订阅栏独立滚动。缺失模组补齐位于列表下方的折叠区域，有缺失时默认展开，原审阅和逐项结果流程保留。

## 数据与范围

- 封面、更新时间、订阅数和标签来自 Steam SDK。封面只允许 HTTPS 的 `steamstatic.com`、`steamusercontent.com` 及其子域，以及 `steamuserimages-a.akamaihd.net`，拒绝账号密码、非默认端口及越界 URL；CSP 只向这些域放开图片。远端图像懒加载且不发送页面来源，失败回退本地封面或统一占位。
- 初版分类使用 Steam 标签：Alternative History、Gameplay、Graphics、Translation，后续已扩展，见上方当前筛选。Translation 是翻译模组类别，不承诺自动翻译模组内容。
- SDK 未提供文件大小，不显示虚构大小；订阅数无法安全转换时省略。未增加合集、自动翻译、批量订阅等未实现入口。
- 保留 0.20.1 的显式连接与超时恢复逻辑，未连接时读取页面不初始化 SDK。初次连接后默认浏览工坊，右侧同时显示订阅。
- 新增 13 个文案键并完整翻译至既有界面语言，简体中文使用原文。账号、作者标题、描述与标签不作为程序文案翻译。
